# EDA(Exploratory Data Analysis)
<br>
EDA is a process used in data mining to analyze and summarize datasets, uncovering patterns, spotting anomalies, testing hypotheses, and checking assumptions with the help of statistical and graphical methods. It helps in understanding the structure of the data and guiding further analysis or modeling.
<br>
Steps:
Understand the Dataset: Identify the data source, types of variables, and overall structure.
<br>
Clean the Data: Handle missing values, duplicate entries, and incorrect data types.
<br>
Univariate Analysis: Analyze each variable separately using statistics like mean, median, and visualizations like histograms or box plots.
<br>
Bivariate/Multivariate Analysis: Explore relationships between variables using scatter plots, correlation matrices, and cross-tabulations.
<br>
Identify Outliers: Detect and analyze unusual data points using box plots or z-scores.
<br>
Transform Data: Apply scaling, encoding, or other transformations to prepare for modeling.
<br>
Summarize Insights: Compile observations and insights for decision-making or deeper analysis.
